================================================
  通译（Tongyi）汉化补丁（游戏里显示中文的那部分）
================================================

版本 v0.2.3：适配 2026-09-30 的 Deadlock Build 25614556。

（中文说明；文件名用 ASCII 是为了压缩包不乱码）


【一】这是啥，干什么用
------------------------------------------------

  tongyi-pak01_dir.vpk

  翻译器负责"把英文翻成中文"，这个补丁负责"把中文显示在聊天框里"。
  它放在游戏的界面资源里，由 Deadlock Mod Manager (DMM) 管理。


【二】怎么装（用 DMM）
------------------------------------------------

  1. 打开 Deadlock Mod Manager（下载：https://deadlockmods.app）
  2. 左边选 My Mods
  3. 点「添加本地 mod / 导入本地文件」
  4. 选中 mod\tongyi-pak01_dir.vpk **这个文件**
  5. 起个名字，比如 通译，然后在「我的模组」里**启用**
  6. 之后用 DMM 的 Launch Modded 启动游戏

  如果 DMM 不接受这个文件名，把 tongyi- 前缀去掉、改成 pak01_dir.vpk 再导入
  （内容完全一样）。


【三】怎么知道装上了
------------------------------------------------

  进游戏后，聊天输入行上方应该出现一行写着「通译」的小字，
  输入框右边还会多一个「设置」按钮和一个小圆点：

      有那行字       = 补丁生效了
      完全没有       = 补丁没生效，回 DMM 看是不是启用状态
      灰色小圆点     = 当前聊天界面尚未完成连接检测
      黄色小圆点     = 有一次连接波动，正在确认
      红色小圆点     = 当前界面连续连接失败（看面板「连接与诊断」）

  打开设置面板：
  按 Enter 打开聊天框，在输入框里输入 /tongyi 后回车
  （/通译、/设置、/dlchat 等价，中文别名不用切输入法）。
  面板弹出后按一下 Tab 调出鼠标才能点按钮；Tab 没反应就再按一下回车。
  输入框右侧那个「设置」按钮也能打开，效果一样。
  详细说明见包根目录的 README-zh.txt【四】。


【四】参考项目
------------------------------------------------

      BabelTower   https://github.com/c1375rick/BabelTower

  ⚠️ 不要和 BabelTower 同时启用：两个都会替换聊天界面文件，
     一起用会互相冲突（谁生效取决于加载顺序）。
     装本 mod 之前，先在 DMM 里停用 BabelTower。


【五】更新 / 卸载
------------------------------------------------
  更新：下载新版玩家包，退出游戏，在 DMM 里移除旧版通译，再导入并启用新版 VPK。
        翻译器（tongyi_launch）不用重装。
        更新后通过 DMM 的 Launch Modded 启动，重新应用游戏的 mod 加载配置。

  本次修复了缺少 TargetHeroImage / TypingIndicatorChatMessage 导致的 FATAL ERROR。
  如果更新后仍报这些错误，检查 game\citadel\addons 中是否残留旧通译的重复 VPK；
  先备份，仅移出确认属于旧通译的包，不要清空其他 mod。

  卸载：在 DMM 里删除本 mod 即可，游戏文件会恢复原样。
