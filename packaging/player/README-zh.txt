================================================
  通译（Tongyi）—— 《Deadlock》聊天实时汉化
================================================

版本 v0.2.3：适配 2026-09-30 的 Deadlock Build 25614556。

别人发的英文，聊天框里直接显示中文；
你打的中文，也能转成英文发出去。

（本文件是中文说明；文件名用 ASCII，是为了让压缩包在任何解压工具下都不乱码）


【一】这个包里有啥，分别干什么用
------------------------------------------------

  tongyi_launch\   —— 翻译器
      跑在电脑上的小程序，负责"把英文翻成中文"。
      它自己不显示东西，是给游戏当后台用的。

  mod\             —— 汉化补丁
      装进游戏的界面补丁，负责"把中文显示在聊天框里"。

  两个都要装：只装翻译器 = 翻好了但游戏里看不见；
              只装补丁   = 界面有了，但没有任何中文。


【二】怎么装（三步，只做一次）
------------------------------------------------

  第 1 步  装翻译器

      双击  tongyi_launch\START_HERE.bat
      它会生成一行配置并复制到剪贴板，然后：
      Steam → 库 → 右键 Deadlock → 属性 → 启动选项 → 粘贴（Ctrl+V）

      粘进去的内容长这样（路径按你解压的位置，别改）：

          "D:\你的文件夹\tongyi_launch\tongyi-launch.exe" %command%

  第 2 步  装汉化补丁

      下载 Deadlock Mod Manager（DMM，社区通用的 mod 管理器）：
          https://deadlockmods.app

      打开 DMM → My Mods → 添加本地 mod
      → 选中这个包里的 mod\tongyi-pak01_dir.vpk 文件 → 起个名字 → 在「我的模组」里启用

  第 3 步  填一次翻译用的 Key

      在 DMM 点击 Launch Modded 开一次游戏，然后浏览器打开：

          http://localhost:8791/settings

      把你自己的 DeepSeek Key 粘进去保存（注册：https://platform.deepseek.com）
      Key 只存在你自己电脑上，不会发给任何人，也不在这个包里。

  完成。以后使用 DMM 的 Launch Modded 启动游戏，
  翻译器跟着游戏一起开，退出游戏后自动关。


【三】怎么知道成功了
------------------------------------------------

  进游戏后看聊天输入框右边的小圆点：

      绿色 = 一切正常
      灰色或红色 = 翻译器没连上

  是灰的，就打开 %APPDATA%\deadlock-tongyi\logs\launcher.log 看原因。


【四】怎么打开设置界面
------------------------------------------------

  A. 游戏内设置面板（调翻译相关的所有选项，最常用）

  在游戏里按 Enter 打开聊天框 → 在输入框里输入下面任意一条 → 按回车：

         /tongyi       ← 记这一条就够了
         /通译  /设置  /dlchat       ← 完全等价，哪个顺手用哪个

     （这行命令不会被发到聊天里，只是用来打开面板。中文那几个别名是给
       中文输入法准备的：不用切英文输入法也能敲。）

     面板标题是「聊天翻译」，选项按「收与发 / 聊天呈现 / 翻译引擎 /
     连接与诊断」分组：

         ★ 重要：面板是用鼠标点的，但游戏里平时没有鼠标指针 ——
           需要按一下 Tab 把鼠标调出来，才能点面板上的按钮。
           按 Tab 没反应的话，再按一下回车。（面板关掉时鼠标会自己收回去。）

        翻译收到的消息（英 → 中）      开 / 关
        中文输入转英文（中 → 英）      开 / 关
        译文显示（收到的消息）         英文 | 中文 / 只显示中文
        我发出去的消息                 中英都发 / 只发英文
        中英之间的分隔符               中文 | 英文 …
        悬停显示英文原文               开 / 关
        触发键                         两下空格 / 三下空格
        翻译来源                       DeepSeek 云端 / 本地 Ollama
        翻译模型                       点开选具体模型
        术语表（英雄/物品名保护）      开 / 关

     顶部按钮：保存设置 · 关闭
     底部按钮：试翻一句 · 重译最近一条 · 最近译文 · 重新读取
     改动后顶部按钮会变成「保存更改」，点它才会写入并生效。面板里的「最近错误」
     会保留翻译失败原因。一次状态探测失败只表示连接波动；连续失败时提示
     「当前界面暂未连通」，头顶气泡使用独立通道，仍可能正常翻译。

     另一种打开方式：按 Enter 打开聊天框后，点输入框右侧的「设置」按钮。
     按钮和上面的命令效果一样，记住 /tongyi 就不用找它了。

  B. 浏览器页面（只用来填 API Key）

         http://localhost:8791/settings

     游戏开着的时候打开，把 Key 粘进去保存一次即可。
     顺便能看到翻译器状态：http://localhost:8791/api/v1/health


【五】参考项目
------------------------------------------------

  界面显示的做法参考了这个开源项目（同样是 Deadlock 聊天翻译）：

      BabelTower   https://github.com/c1375rick/BabelTower

  ⚠️ 两个不要同时启用：都会替换聊天界面文件，一起用会互相冲突。
     想换过去，先在 DMM 里停用本 mod。


【六】常见问题
------------------------------------------------

  · 点了开始游戏，游戏没反应？
      启动选项里的引号或路径写错了：重新双击 START_HERE.bat 再粘一次。
      （挪动过文件夹位置，也必须重新生成。）

  · 游戏里找不到「设置」按钮？
      说明汉化补丁没生效（那个按钮是补丁加上去的），回 DMM 看是不是启用状态。

  · 更新游戏后出现 TargetHeroImage 或 TypingIndicatorChatMessage 的 FATAL ERROR？
      这是旧版聊天布局与新版游戏不兼容。退出游戏，在 DMM 中移除旧版通译，
      再导入本包的 mod\tongyi-pak01_dir.vpk，并使用 Launch Modded 启动。
      如果仍报错，检查游戏 game\citadel\addons 是否残留旧通译的重复 VPK；
      先备份，仅移出确认属于旧通译的文件，不要清空其他 mod。
      Steam 启动选项也要保留 START_HERE.bat 生成的内容，否则翻译桥不会随游戏启动。

  · 不想让它自动启动了？
      清空 Steam 的启动选项即可，游戏照常能玩，只是没有翻译。

  · 怎么卸载？
      ① 清空 Steam 启动选项  ② 删掉这个文件夹
      ③ 在 DMM 里删掉本 mod  ④ 想清干净再删 %APPDATA%\deadlock-tongyi\

  · 会拖慢游戏吗？
      不会。翻译器只在游戏运行时存在，空闲时几乎不占 CPU；
      翻译发到云端做，不占显卡。

  · 杀毒软件报警？
      打包的小程序偶尔会被误报，添加信任即可。
      它不改游戏文件、不注入进程，只发网络请求。


【tongyi_launch\ 里的其他文件】
------------------------------------------------
  README-zh.txt           本说明文件（中文），另一份拷在压缩包根目录
  tongyi-launch.exe       翻译器本体（无窗口），由 Steam 启动选项调用
  tongyi-launch-cli.exe   同上但带控制台窗口，出问题时用它看输出
  START_HERE.bat          生成 Steam 启动选项（先双击这个）
  config.yaml             默认配置，一般不用动（**不要**把 Key 写这里）
  _internal\              运行时文件，别删
